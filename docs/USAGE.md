# Cara Pakai HUBLR

## Pencarian

Ketik di search bar, tekan Enter.

## Shortcut Engine

- `g: kata` → Google
- `b: kata` → Bing
- `d: kata` → DuckDuckGo
- `y: kata` → YouTube
- `gh: kata` → GitHub
- `w: kata` → Wikipedia

## Kalkulator

Ketik ekspresi matematika: `2+2`, `(10*5)/2`, dll.

## Bookmark

Klik ➕ untuk tambah. Hover kartu untuk hapus.

## Pengaturan

Klik ⚙️ di kanan atas.

## Ganti Bahasa

Klik tombol ID/EN di kanan atas.
