# 🎯 Cara Pakai HUBLR

---

## 🔍 Pencarian

1. Klik kolom pencarian (atau tekan `Ctrl + K`)
2. Ketik kata kunci
3. Tekan **Enter**

### Ganti Mesin Pencari

Klik dropdown di kiri search bar → pilih mesin pencari.

---

## ⚡ Shortcut Mesin Pencari

Ketik `<kode>: <kata kunci>` untuk langsung cari di mesin tertentu.

| Kode | Mesin | Contoh |
|---|---|---|
| `g:` | Google | `g: cara coding` |
| `y:` | YouTube | `y: tutorial react` |
| `gh:` | GitHub | `gh: awesome list` |
| `w:` | Wikipedia | `w: Soekarno` |
| `b:` | Bing | `b: berita` |
| `d:` | DuckDuckGo | `d: privacy` |

---

## 🧮 Kalkulator

Langsung ketik ekspresi matematika di search bar:

| Ketik | Hasil |
|---|---|
| `2+2` | `= 4` |
| `10*5` | `= 50` |
| `(100-20)/4` | `= 20` |
| `50%` | `= 0.5` |

Hasil muncul otomatis saat mengetik.

---

## 🔖 Bookmark

- **Tambah**: Klik ➕ di header Bookmark
- **Hapus**: Hover kartu → klik ✕
- **Buka**: Klik kartu

Bookmark disimpan di browser (LocalStorage), tidak dikirim ke server.

---

## 🌓 Ganti Tema

Klik tombol 🌙 / ☀️ di kanan atas.

---

## 🌐 Ganti Bahasa

Klik tombol `ID` / `EN` di kanan atas.

---

## ⚙️ Pengaturan

Klik tombol ⚙️ di kanan atas. Ada opsi:
- Wallpaper
- Animasi
- Format jam (12/24)

---

## ⌨️ Keyboard Shortcuts

| Tombol | Fungsi |
|---|---|
| `Ctrl + K` | Fokus search |
| `/` | Fokus search |
| `Enter` | Cari |
| `Esc` | Bersihkan search |
