# ⌨️ Keyboard Shortcuts

---

## Daftar Shortcut

| Tombol | Fungsi |
|---|---|
| `Ctrl + K` | Fokus ke search bar |
| `Cmd + K` | Sama (Mac) |
| `/` | Fokus ke search bar |
| `Enter` | Cari |
| `Esc` | Bersihkan search / tutup modal |
| `Tab` | Pindah elemen |
| `F5` | Refresh |
| `Ctrl + Shift + R` | Hard refresh |
| `F12` | Buka DevTools |

## Contoh Cepat

**Cari di GitHub:**
1. `Ctrl + K`
2. Ketik `gh: react`
