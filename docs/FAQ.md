## Umum

**Apa itu HUBLR?**
Startpage (halaman pembuka browser) yang minimalis dan ringan, dibuat oleh LAYRAGA OFFICIAL.

**Gratis?**
Ya, 100% gratis. MIT License.

**Butuh Node.js?**
Tidak. Cukup browser.

**Ukurannya berapa?**
< 50KB total.

**Bisa offline?**
Ya, setelah load pertama (PWA).

## Penggunaan

**Cara mencari?**
Klik search bar → ketik → Enter.

**Cara pakai shortcut?**
Ketik `gh: react` → cari di GitHub. Lihat [USAGE.md](USAGE.md).

**Cara ganti bahasa?**
Klik tombol `ID` / `EN` di kanan atas.

**Cara ganti tema?**
Klik tombol 🌙 / ☀️ di kanan atas.

**Cara tambah bookmark?**
Klik ➕ di header Bookmark.

**Cara reset pengaturan?**
Buka Console (`F12`):
```javascript
localStorage.clear(); location.reload();
```
