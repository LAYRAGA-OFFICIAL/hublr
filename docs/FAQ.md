A: Ya, MIT License — bebas dipakai.

**Q: Butuh internet?**
A: Hanya untuk wallpaper & search. Setelah load, bisa offline.

**Q: Datanya disimpan di mana?**
A: Lokal di browser Anda (LocalStorage).

**Q: Bisa dikustomisasi?**
A: Ya, edit `src/js/config.js`.

**Q: Bisa install seperti app?**
A: Ya, lewat PWA.
