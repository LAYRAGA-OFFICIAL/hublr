# Cara Instalasi HUBLR

## Metode 1: Langsung Buka

1. Clone repo: `git clone https://github.com/LAYRAGA-OFFICIAL/hublr.git`
2. Buka `index.html` di browser
3. Selesai!

## Metode 2: Jadikan Homepage

### Chrome / Edge / Brave
1. Settings → On startup → Open a specific page
2. Tambah URL HUBLR

### Firefox
1. Settings → Home → Custom URLs
2. Tambah URL HUBLR

## Metode 3: PWA (Install)

1. Buka HUBLR di browser
2. Klik ikon "Install" di address bar
3. HUBLR akan terinstall seperti app
