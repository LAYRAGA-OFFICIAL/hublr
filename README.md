## ✨ Fitur

- 🔍 Multi search engine
- 🕐 Jam & tanggal real-time
- 👋 Sapaan otomatis
- 🌓 Dark/light mode
- 🔖 Bookmark manager
- 🖼️ Wallpaper dinamis
- 🧮 Kalkulator built-in
- ⌨️ Keyboard shortcuts
- 🌐 Dwibahasa (ID/EN)
- 📱 PWA ready
- ⚡ Ringan (< 50KB)

## 🚀 Cara Pakai

1. Clone repo: `git clone https://github.com/LAYRAGA-OFFICIAL/hublr.git`
2. Buka `index.html` di browser
3. Selesai!

**Demo live**: https://layraga-official.github.io/hublr/
