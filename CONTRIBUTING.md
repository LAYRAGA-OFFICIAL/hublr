# Contributing to HUBLR

Terima kasih sudah tertarik berkontribusi! 🎉

## Cara Kontribusi

1. Fork repo
2. Clone: `git clone https://github.com/LAYRAGA-OFFICIAL/hublr.git`
3. Buat branch: `git checkout -b fitur-keren`
4. Commit: `git commit -m "Tambah fitur keren"`
5. Push: `git push origin fitur-keren`
6. Buat Pull Request

## Aturan

- Gunakan bahasa Indonesia atau Inggris
- Tulis kode rapi
- Sertakan komentar
- Test dulu sebelum push

Lihat [README.md](README.md) untuk struktur folder.
