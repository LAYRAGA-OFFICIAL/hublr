# Contributing to HUBLR

Terima kasih sudah tertarik berkontribusi! 🎉

## Cara Kontribusi

1. **Fork** repo ini
2. **Clone** fork Anda:
   ```bash
   git clone https://github.com/USERNAME/hublr.git
   cd hublr
   ```
3. **Buat branch** baru:
   ```bash
   git checkout -b fitur-keren
   ```
4. **Commit** perubahan:
   ```bash
   git commit -m "Tambah fitur keren"
   ```
5. **Push** ke branch:
   ```bash
   git push origin fitur-keren
   ```
6. **Buat Pull Request** di GitHub

## Aturan

- Gunakan bahasa Indonesia atau Inggris
- Tulis kode rapi dan mudah dibaca
- Sertakan komentar untuk logika rumit
- Test dulu sebelum push
- Jangan ubah file konfigurasi tanpa alasan jelas

## Ide Kontribusi

- 🐛 Lapor bug
- 💡 Usul fitur
- 📖 Perbaiki dokumentasi
- 🌐 Terjemahkan ke bahasa lain
- ⭐ Beri bintang di GitHub
