# Security Policy

## Versi yang Didukung

| Versi | Didukung |
|-------|----------|
| 0.1.x | ✅ |
| < 0.1.0 | ❌ |

## Melaporkan Kerentanan

Jika Anda menemukan kerentanan keamanan, **JANGAN buka issue publik**.

Gunakan salah satu cara berikut:

1. **GitHub Security Advisory** (cara utama):
   https://github.com/LAYRAGA-OFFICIAL/hublr/security/advisories/new

2. **GitHub Discussions** (untuk diskusi umum):
   https://github.com/LAYRAGA-OFFICIAL/hublr/discussions

## Yang Perlu Dilaporkan

- XSS (Cross-Site Scripting)
- Code injection
- Data leakage
- Dependency vulnerability
- Masalah privasi

## Respon Kami

- **48 jam**: Konfirmasi penerimaan laporan
- **7 hari**: Analisis awal
- **30 hari**: Perbaikan & rilis

## Penghargaan

Kontributor yang melaporkan kerentanan valid akan dicantumkan di [CHANGELOG.md](CHANGELOG.md).
